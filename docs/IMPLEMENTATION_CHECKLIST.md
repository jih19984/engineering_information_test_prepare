# ITPE Prep 구현 체크리스트

정보처리기사 실기 학습 플랫폼 MVP를 직접 구현할 때 따라갈 수 있는 작업용 체크리스트입니다.

## 사용 방법

- 완료한 항목은 `- [x]`로 바꾸기
- 아직 진행 전이면 `- [ ]` 유지
- 메모가 필요하면 항목 아래에 한 줄로 기록

예시:

```md
- [x] Next.js 프로젝트 생성
- [ ] Clerk 로그인 연동
메모: Clerk 대시보드에서 Redirect URL 설정 필요
```

- [ ] `notes`는 본인 데이터만 읽기 허용
