# ITPE Prep

정보처리기사 실기 학습용 웹서비스 프로젝트입니다.

## 개발 환경

- Next.js App Router
- TypeScript
- Tailwind CSS
- pnpm

## 시작하기

의존성 설치:

```bash
pnpm install
```

개발 서버 실행:

```bash
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열면 됩니다.

## 검증 명령

```bash
pnpm lint
pnpm test
pnpm build
```
